---
title: "ai_classify"
---

The `ai_classify` function assigns each row one label out of a fixed list of choices and returns that label as `VARCHAR`. It is served only by [`typesafe` models](/getting-started/typesafe), where Jev answers one choice question per row.

## 1. Usage

The choices can be plain labels:

```sql
SELECT text,
       ai_classify(
           {'model_name': 'jev'},
           {'prompt': 'Classify the topic of this news article.',
            'choice': ['World', 'Sports', 'Business', 'Sci/Tech'],
            'context_columns': [{'data': text}]}
       ) AS topic
FROM articles;
```

Or labels with a description, which helps Jev tell close labels apart:

```sql
SELECT transcript,
       ai_classify(
           {'model_name': 'jev'},
           {'prompt': 'Identify the customer''s main complaint.',
            'choice': [{'label': 'billing', 'description': 'Payments, invoices, and refunds'},
                       {'label': 'technical', 'description': 'Errors, outages, and integrations'},
                       {'label': 'account', 'description': 'Cancellations and account administration'}],
            'context_columns': [{'data': transcript}]}
       ) AS complaint
FROM tickets;
```

## 2. Input Parameters

- **Model**: a `typesafe` model, for example `{'model_name': 'jev'}`. Other providers refuse `ai_classify` when the query is planned.
- **Prompt**: the task, given inline with `prompt` or as a saved prompt with `prompt_name`.
- **`choice`**: the labels to choose from, as a list of strings or of `{'label', 'description'}` structs. Jev accepts up to 255.
- **`context_columns`**: the row data to classify. Columns must be text.

## 3. Output

The chosen label, as `VARCHAR`. A row whose context values are all `NULL` is not sent and returns `NULL`.

Every row's question carries the full list of choices, so the cost of a batch grows with the number of rows times the number of choices.
